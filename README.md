# Passenger Counter App

This is an interactive web application built as part of the Scrimba Frontend Developer Career Path. The goal was to build a digital counter that tracks and logs data, replacing the need for a physical manual tally counter.

## Key Features

- **Increment:** A button that increases the count in real-time.
- **Save & Log:** Records the current count into a "Previous Entries" log using string concatenation.
- **Reset Logic:** Resets the count to zero for the next batch of entries.

## What I Learned

This project focused on the fundamentals of JavaScript and the DOM:

- **DOM Manipulation:** interacting with HTML elements using `document.getElementById()`.
- **Text rendering:** Understanding the difference between `.innerText` and `.textContent`.
- **Event Listeners:** Using `onclick` attributes to trigger functions.
- **Basic Logic:** Working with variables, increment operators, and string concatenation to display logs.
